Cómo se arregla

El naranja de marca se conserva tal cual para superficies (íconos, fondos, el módulo oscuro). Solo se agregan variantes oscuras para cuando es texto o lleva texto blanco encima — exactamente el patrón que tu sistema ya usa hoy con --primary-text.
