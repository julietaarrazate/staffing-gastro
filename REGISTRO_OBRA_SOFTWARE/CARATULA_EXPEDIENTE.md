## 3. DESCRIPCIÓN SINTÉTICA

Oído es un marketplace web que conecta comercios gastronómicos con trabajadores eventuales para cubrir turnos de trabajo puntuales en tiempo real. Incorpora un motor de matching con scoring multi-factor, un sistema de verificación de identidad por niveles de garantía, un motor de insignias y niveles de gamificación, y un asistente de inteligencia artificial para publicar turnos por texto libre.

**Componentes:**
- Backend API + WebSocket (FastAPI + Python, arquitectura DDD/hexagonal en 17 módulos)
- Frontend web (Next.js + TypeScript, PWA instalable)
- Base de datos relacional (PostgreSQL — Neon) con migraciones versionadas
